# Integrations

You can bring your own tools.
You can leave every key empty.
The built-in list then does the work.
The built-in tools need no keys.

`packages/integrations` is optional.
The app runs when that package is absent.
When the package is present, sponsor match can call `companySize` and `lumaEventHosts`.
Approve can call `pushDeal`.
Recall can call Cognee.
The dashboard calls `getStatus()`.

## Providers

| Provider | Environment variable | What it does | Built-in fallback |
| --- | --- | --- | --- |
| Built-in list | None | Sponsors and deals stay in Sponsor Engine. | This is the default. |
| Zero | `ZERO_API_KEY` | Copy an approved deal into Zero. | The deal stays in Sponsor Engine. |
| Twenty | `TWENTY_API_URL` and `TWENTY_API_KEY` | Copy an approved deal into Twenty. | The deal stays in Sponsor Engine. |
| Cognee | `COGNEE_API_KEY` | Remember past events and answer recall. | The local database. |
| Luma | None | Read hosts from public Luma pages. | The bundled London list. |
| Devpost | None | Read public hackathon pages. | The bundled London list. |
| Companies House | `COMPANIES_HOUSE_API_KEY` | Look up the size of a UK company. | The match still returns. It has no size. |
| Meetup | None | Public Meetup pages are already in the bundled tables. | The bundled list. There is no live Meetup key. |
| Email | `DRY_RUN` and `ALLOWLIST` | Mark a message sent only after approval. | Test mode writes a log. It does not send. |
| HubSpot | None | HubSpot is not available yet. | The built-in list. |
| Sheets | None | Google Sheets is not available yet. | The built-in list. |

Luma and Devpost need the integrations package for a live fetch.
They do not need a key.
Meetup names in the bundle come from public pages that were read on 22 October 2026.
The server does not call Meetup at request time.

## Environment variables

Copy `.env.example` to `.env` only when you want to change a value.

| Name | Default | Purpose |
| --- | --- | --- |
| `DRY_RUN` | `true` | Test mode. `true` does not send. |
| `ALLOWLIST` | empty | Addresses that can be marked sent when `DRY_RUN` is `false`. Separate addresses with a comma. |
| `DATABASE_URL` | empty | Leave empty to use SQLite. A `postgres://` URL uses Postgres. |
| `SPONSOR_ENGINE_DB` | `data/sponsor-engine.db` | Path of the SQLite file. |
| `PORT` | `8787` | Port for the MCP HTTP server. |
| `ZERO_API_KEY` | empty | Use Zero instead of only the built-in list. |
| `TWENTY_API_URL` | empty | Use Twenty. Set this with `TWENTY_API_KEY`. |
| `TWENTY_API_KEY` | empty | Use Twenty. Set this with `TWENTY_API_URL`. |
| `COGNEE_API_KEY` | empty | Use Cognee for memory. |
| `COMPANIES_HOUSE_API_KEY` | empty | Look up a UK company size. |

## Channel text

`triage_inbound` stores the `channel` string you send.
The tool description names `whatsapp`, `email`, and `web`.
You can also send `discord`, `telegram`, or `slack`.
The server stores the text.
The server does not open those chats by itself.
