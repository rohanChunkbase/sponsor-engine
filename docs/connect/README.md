# Connect

You keep your own chat app. You keep your own agent. Sponsor Engine does not replace them.

The HTTP server is streamable MCP. It listens on `http://127.0.0.1:8787/mcp`. `MCP_TOKEN` is optional.

The hosted route is `/api/mcp`. The local server and that route use one handler. Approve is not a tool. A person approves on the dashboard.
