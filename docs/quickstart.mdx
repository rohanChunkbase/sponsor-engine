Sponsor Engine is the front desk and the sponsor desk for a community or a venue.
You call it from the agent you already pay for.
You can also use the web dashboard.
The licence is MIT.

MCP means Model Context Protocol.
The server name is `sponsor-engine`.

## Requirements

You need Node.js 22.
You can start with no API key.
Every environment variable is optional.

## Start the dashboard

1. Open a terminal.
2. Go to the project folder.
3. Run this command.

```bash
npm install && npm run dev
```

4. Open `http://localhost:3000`.
5. Press **Run demo** on the inbox.

The first start loads the bundled data.
The inbox stays empty until a message arrives.
The start command builds the pricing package when that build is missing.

Two more commands are useful.

```bash
npm test
npm run demo
```

`npm test` builds the pricing package.
It then runs the package tests.

## Start the MCP server

1. Open the MCP settings in your agent.
2. Paste the config on the [Connect your agent](/connect) page.
3. Set the working directory to the project folder.
4. Keep `DRY_RUN` set to `true`.

You can start the stdio server in a terminal.

```bash
npm run mcp
```

You can start the HTTP server.

```bash
npm run mcp:http
```

The HTTP server listens on `http://127.0.0.1:8787/mcp`.

## What a run does

The tools read one message.
The tools make a quote from past bookings.
The tools match sponsors and keep the source link.
The tools write a sponsor email.
The email waits in the outbox.
A person approves the email.
Test mode does not send the email.

Read the [MCP tools reference](/tools) for each input and each example.
Read [Safety](/safety) before you change `DRY_RUN`.
The room quote method is on the [Pricing](/pricing) page.

<Warning>
Keep DRY_RUN set to true on the first day. True means the server does not send.
</Warning>
